# Transaction Data Analysis Python Project

This repository contains a Python project for **transaction data analysis**. The goal of the project is to analyze transaction data and extract insights about customer behavior, transaction frequency, amount, and more.

## Contents
- **Data**: Customer transaction data (e.g., amounts, ATMs, etc.).
- **Python**: Used for data analysis and visualization (Pandas, Matplotlib, Seaborn).
  
## Technologies Used
- **Python**: Pandas, Matplotlib, Seaborn, Numpy.
- **CSV**: Data stored in CSV files.

## Project Objective
The objective of this project is to **analyze transaction data** and **understand customer behavior**. Various visualizations have been created to showcase insights from transaction amounts, ATM usage, customer segmentation, and more.

## Project Sections
1. **Data Loading**:
    - Loading transaction data (`Dim_transaction_type.csv`), customer data (`Dim_customers.csv`), and other related datasets.
2. **Data Analysis**:
    - Cleaning and analyzing data using Pandas (e.g., average transaction amounts, customer segmentation).
3. **Visualization**:
    - Creating various plots and visualizations using Seaborn and Matplotlib (e.g., distribution of transaction amounts, ATM analysis).
4. **Statistical Analysis**:
    - Performing deeper analysis using statistical methods (hypothesis testing, K-means clustering, etc.).
